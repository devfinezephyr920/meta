# 内置公共订阅的风险

一句话：客户端「自动拉取公共订阅、开箱即用」，意味着你的流量会经过一批你不知道由谁运营的服务器，而且拉取来源由客户端作者决定、随时可以改。

## 风险在哪

| 风险 | 说明 |
| --- | --- |
| 节点运营者未知 | 流量经过谁的服务器无从得知，对方理论上能看到未加密的内容与访问记录 |
| 来源由客户端决定 | 拉取地址写在客户端里，更新后换成什么你看不到 |
| 客户端本身来源不明 | 非原作者构建、未声明许可证、调试构建，安装包内容无法核对 |
| 可用性不稳定 | 公共节点随时失效，客户端自动清理后可能长期无可用节点 |

## 最低限度的做法

- 不在这类连接下登录任何账号，尤其是邮箱、支付、工作系统。
- 不在主力手机上安装来源无法核对的代理客户端。
- 客户端只从能对上作者的发布页下载，见 [可核对来源的客户端](verified-clients.md)。

## 自己的订阅也要保管好

从服务商购买的订阅链接带着代表你账号的字符。不要导入到来源不明的客户端里，这类客户端可以读取并上传你导入的链接。
