## 核对一个仓库的五件事

1. 所有者是不是上表里的作者。
2. 是否标着「forked from」。
3. 有没有声明许可证。
4. Releases 页的 Latest 版本号与日期。
5. 发布文件名里有没有 debug、alpha 这类非正式构建的字样。

这些客户端本身都不带线路，需要导入你自己从服务商获得的订阅。
